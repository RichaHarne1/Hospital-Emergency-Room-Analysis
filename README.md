# Hospital-Emergency-Room-Analysis
Hospital Emergency Room Data Analysis using Microsoft Excel

## 📊 Project Overview

This project analyzes hospital emergency room data using Microsoft Excel to identify key patterns related to patient visits, wait times, admissions, demographics, and overall emergency room performance.

The objective is to transform raw hospital emergency room data into meaningful insights using Excel-based data cleaning, analysis, Pivot Tables, charts, and an interactive dashboard.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Data Analysis
* Dashboard Development


## 🔍 Key Analysis Areas

* Total number of emergency room visits
* Patient demographics
* Average waiting time
* Patient satisfaction
* Admission vs. non-admission
* Department/referral analysis
* Gender and age-group analysis
* Patient visit trends
* Emergency room performance indicators

## 📈 Excel Techniques Used

* Data Cleaning
* Sorting & Filtering
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Conditional Formatting
* Data Visualization
* KPI Analysis
* Dashboard Creation

## 💡 Key Insights

The analysis was used to identify patterns in patient visits, waiting times, admissions, demographics, and emergency room performance.

The dashboard provides a consolidated view of important emergency room KPIs and enables users to explore the data through interactive Excel visualizations.

## 🎯 Business Objective

The purpose of this project is to demonstrate how Excel can be used to transform raw healthcare-related data into actionable insights that can support operational monitoring and decision-making.
